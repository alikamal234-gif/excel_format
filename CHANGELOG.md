# Change Log

All notable changes to the "Excel Viewer Pro" extension will be documented in this file.

## [1.0.0] - 2024-01-01

### Added
- Initial release of Excel Viewer Pro
- View Excel files (.xlsx, .xls, .xlsm) in a spreadsheet grid
- Edit cells with double-click or Enter/F2
- Formula bar for cell value editing
- Multiple worksheet tabs support
- Search functionality (Ctrl+F) with navigation
- Export sheets as CSV or JSON
- Column resize by dragging
- Context menu with insert row/column and clear cell
- Arrow key navigation between cells
- Automatic VS Code theme support (Light, Dark, High Contrast)
- Status bar with cell count and selection info
